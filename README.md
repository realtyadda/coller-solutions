# Coller Solutions LLP

Standalone static company website, exported from the approved mobile-alignment release on 15 September 2026.

## Repository
Create a separate repository named `coller-solutions` under the GitHub account associated with `shekhar.ch90@gmail.com` (username: `realtyadda`). Do not upload these files to the existing `realtyadda` repository.

## Publish
Upload the contents of this folder to the new repository root. In Settings > Pages, select Deploy from a branch, main, /(root). Leave Custom domain blank. No build step or external dependencies are required.

## Domain later
No CNAME file or custom domain is configured. Canonical URLs and the sitemap should be set once the final publishing address is confirmed. Existing domain and email DNS must be preserved until the authorised domain change.

## Enquiries
The form prepares an email or WhatsApp message. The visitor must send it in their selected app. WhatsApp messages to both numbers require separate sends. There is no database or automatic submission endpoint.

## Included
18 pages, 12 detailed solutions, AMC and Support, company profile download, two contact numbers, responsive CSS and associated images. The completed-project showcase is deferred.
